# Usando as Skills RVF sem terminal

Escolha o guia correspondente à ferramenta que você usa:

| Ferramenta | Como funciona | Guia |
|---|---|---|
| Claude no navegador ou app desktop | Upload de cada skill em **Personalizar → Skills** | [Instalar no Claude](docs/INSTALACAO-CLAUDE.md#claude-no-navegador-ou-app-desktop) |
| ChatGPT no navegador | Configuração em um Projeto ou, quando disponível, em um GPT | [Configurar no ChatGPT web](docs/INSTALACAO-CHATGPT.md) |
| ChatGPT desktop com Codex | Pedido de instalação feito no próprio chat | [Instalar no ChatGPT desktop](docs/INSTALACAO-CODEX.md#chatgpt-desktop-com-codex) |

Se você não sabe qual skill escolher, consulte a [tabela de finalidades](README.md#qual-skill-usar).

Depois da configuração, descreva a demanda normalmente ou cite a skill pelo nome:

```text
Use conducao-estrategica-de-comunicacoes para planejar esta mensagem.
```
